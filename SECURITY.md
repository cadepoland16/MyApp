# Security Policy

## Reporting

If you find a security issue, do not open a public issue with exploit details.

Report it privately to the maintainer first and include:

- a clear description of the issue
- steps to reproduce
- expected impact
- any suggested mitigation

## Scope Notes

This project depends on local environment configuration and third-party services such as Supabase and Ollama. Security findings may involve:

- exposed secrets in configuration
- unsafe API behavior
- insecure prompt or model-routing behavior
- dependency vulnerabilities

Please allow time for triage before public disclosure.
